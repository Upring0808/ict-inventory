# Product Design System

## Direction

Professional government/internal enterprise application.

The interface should feel:
- clean
- trustworthy
- modern
- understated
- efficient
- information-dense without feeling crowded

Avoid:
- obvious AI-generated SaaS styling
- excessive gradients
- glassmorphism everywhere
- excessive rounded cards
- cards nested inside cards
- oversized headings
- unnecessary animations
- giant empty spaces
- decorative UI without function

## Typography

Strong visual hierarchy.

Page title:
- 28–32px
- semibold

Section heading:
- 18–20px
- semibold

Body:
- 14–16px

Metadata:
- 12–14px
- muted

## Spacing

Use a consistent spacing scale:
4 / 8 / 12 / 16 / 24 / 32 / 48

Prefer generous internal spacing but compact dashboard density.

## Components

Use consistent:
- buttons
- tables
- dialogs
- filters
- form fields
- status badges
- dropdowns
- empty states
- toast notifications

## UX

Every major action should have:
- loading state
- error state
- success feedback
- disabled state where appropriate

Tables should support:
- readable alignment
- clear row hierarchy
- search
- filtering
- pagination
- responsive behavior

## Responsive

Design desktop-first for admin workflows,
but ensure usable layouts down to mobile widths.
